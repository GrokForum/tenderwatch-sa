## 1. Goal

Clear five queued BAU items on one branch, without changing publish paths or the site repository.

## 2. What changes (exact files)

1. **Privacy page wording (CHG-TW-006, critic nit).** `tw/site.py` `render_privacy()`: the corrections section no longer asks a correspondent to identify a masked row by "usable value". It asks for the award date and tender reference, or, where no tender reference is shown, the buyer and the award value shown on the row. Neutral tone; the method page is unchanged.
2. **CHG-TW-008 RFC, stale sentence.** `docs/rfc/CHG-TW-008.md` §4: the local `confirmed_suppliers.csv` is regenerated by the refresh and is not a second detail. Each hold's second detail is the record's `name_key` (already the rule in §2, revision 3).
3. **Generic words as tracked config.** The hard-coded set in `tw/site_build.py` moves to `config/generic_words.txt` (one word per line). `load_generic_words()` loads it and fails closed if the file is missing, unreadable or empty.
4. **Holds-file not-tracked test.** `tests/test_site_build.py`: skip when not in this repository's work tree, by checking that `git rev-parse --show-toplevel` equals the repo root. A parent git repository must not make the test run against the wrong tree.
5. **Generic-word exemption.** A generic trade word may appear in a hold basis only when it is not also a word of the held supplier's own name. Tests use invented names only. A missing generic-words file also stops `apply_holds`.

This RFC and one `STATUS.md` row are added. No existing `STATUS.md` row is edited.

## 3. What stays

* The holds file, the two-detail rule, the mask and citation rules, and the automatic one-person-name detector.
* `publish_enabled` and `push_log` stay off; the site repository is not touched.
* Forward-only history: no rebase, no force push.

## 4. Success

* The CHG-TW-008 "What stays" sentence matches the refresh / `name_key` rule.

* The not-tracked test skips unless the git toplevel is this repo root.
* A basis that uses a generic trade word which also occurs in the held (invented) name stops the build; the same word is still allowed when it is not in that name.
