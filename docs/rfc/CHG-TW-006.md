Rules the code enforces and the tests pin:

* **Years.** Only a Confirmed year is published, as `Year: YYYY, Confirmed`. A Reported, Unconfirmed year shows only as `Year: ****, Reported, Unconfirmed` (four fixed asterisks, never a digit). No year: `Year: Unknown`. A JV or trust never shows a year (no CIPC registration). A held masked row never shows a digit; if a lookup ever gives a held row a Confirmed year, the build stops for an owner decision (open question Q1).
* **Mask.** Name stem (outer brackets and any trailing legal-form suffix, including stacked `(RF) (Pty) Ltd` and dotted `C.C.`, removed; ASCII-folded); first character upper case, five asterisks, last character lower case; always 7 characters; fewer than two letters or digits gives `*******`.
* **Nothing identifying next to a mask** (§13.2): no tender reference, OCDS id, release link, registration detail or indicator. On these rows the eTenders tender title is the tender reference itself (273 of the 291 titles are a reference code, and the rest are references with stray spaces or a four-digit year), so it is not shown either.
* **Label.** Every published fact label reads Confirmed, "Reported, Unconfirmed" or Unknown; any other label stops the build.
* **Indicator I1** (§13.4, owner-accepted thresholds): awards and total usable value to the same supplier from one buyer in one municipal financial year; shown at 2 or more, highlighted at 3 or more; only on unmasked rows; neutral template ending "This is a count from the public record, not a finding."; with "Right of reply: pending". Today: 14 rows (7 pairs of supplier and financial year with 2 awards each; supplier matched on the normalised name key), none at 3. The rolling-365-day variant and I2–I7 are not built (they are listed on the method page as defined but not shown).
* **Values** are shown as published; the source's 0 placeholders and implausible values show as "No usable value (…)", never as a number.

## 6. Low audit findings fixed in the same change

* **L2 (favicon 404)**: every page declares `<link rel="icon" href="data:,">`, so browsers do not request `/favicon.ico`.
* **M4 (no CSP)**: every page carries `default-src 'none'; style-src 'unsafe-inline'; img-src 'self' data:; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`. The pages have no script at all. (`frame-ancestors` is ignored in a meta CSP; it is harmless and kept for when headers become possible.)
* **Referrer**: `no-referrer` meta on every page.
